گزارش امروز: ویرایشگر مقاله

آشنایی با Tiptap، دکمه‌های قالب‌بندی متن و بررسی مشکل نمایش فهرست‌ها.

۱. کارهایی که انجام دادیم

  • ساخت و اتصال کامپوننت ArticleEditor.tsx.
  • اضافه‌کردن تیترهای ۲، ۳ و ۴.
  • اضافه‌کردن متن ضخیم، ایتالیک، لینک، بازگشت و انجام دوباره.
  • اضافه‌کردن دکمه‌های فهرست نقطه‌ای و شماره‌دار.
  • بررسی خروجی دکمه‌ها با ابزار Console مرورگر.
  • بررسی استایل‌های CSS برای نمایش علامت‌ها و شماره‌های فهرست.

۲. نکات آموزشی کلیدی

  • useEditor نمونه ویرایشگر Tiptap را ایجاد می‌کند.
  • StarterKit قابلیت‌های پایه مانند تیترها و فهرست‌ها را فراهم می‌کند.
  • editor.getHTML() محتوای ویرایشگر را به HTML تبدیل می‌کند.
  • onChange برای انتقال محتوای جدید به کامپوننت والد استفاده می‌شود.
  • toggleBulletList() فهرست نقطه‌ای را فعال یا غیرفعال می‌کند.
  • toggleOrderedList() فهرست شماره‌دار را فعال یا غیرفعال می‌کند.
  • preventDefault() می‌تواند از ازدست‌رفتن انتخاب متن هنگام کلیک روی دکمه جلوگیری کند.
  • اجرای موفق فرمان لزوماً به معنی نمایش صحیح آن در صفحه نیست؛ CSS هم اهمیت دارد.

۳. نتیجه بررسی فهرست‌ها

در Console این خروجی‌ها ثبت شدند:

Bullet list: true
Ordered list: true

HTML تولیدشده شامل تگ‌های <ul> و <ol> بود؛ بنابراین فرمان‌ها اجرا می‌شوند.

مشکل باقی‌مانده: علامت‌های نقطه‌ای و شماره‌های فهرست در صفحه دیده نمی‌شوند. استایل‌های صریح Tailwind برای فهرست‌ها پیشنهاد شده‌اند، اما نتیجه نهایی هنوز تأیید نشده است.

۴. راهنمای ادامه کار

  1. کلاس editorProps.attributes.class را بررسی کن.
  2. برای ul از list-disc و برای ol از list-decimal استفاده کن.
  3. با نوشتن چند خط متن، هر دو نوع فهرست را دوباره آزمایش کن.
  4. اگر مشکل باقی بود، استایل‌های عمومی پروژه را بررسی کن.

۵. مرحله‌های بعدی پروژه

  • تکمیل و آزمایش فهرست‌ها.
  • افزودن تصویر داخل متن مقاله.
  • تکمیل بلوک کد و نمایش مناسب آن.
  • اتصال فرم مقاله به API بک‌اند و ذخیره محتوا.
